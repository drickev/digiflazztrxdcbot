PROJECT OVERVIEW
───────────────────────────────────────────────────────────────────

sederhana. User tinggal ketik format, bot langsung proses transaksi.

FEATURES
───────────────────────────────────────────────────────────────────

1. TRANSACTION PROCESSING
   • Auto parse format: SKU.nomor/idtujuan
   • Validate input before sending to API
   • Generate MD5 signature for authentication
   • Support all Digiflazz service types

2. RESPONSE SYSTEM
   • Embed messages (colored based on status)
   • Success response (green embed)
   • Failed response (red embed)
   • Pending response (orange embed)
   • Error handling (yellow embed)

3. COMMAND SYSTEM
   • !help - Show help
   • !balance - Check balance
   • !status - Bot status
   • !ping - Response time

4. LOGGING SYSTEM
   • Transaction logging to Discord channel
   • Console logging with timestamps
   • Error tracking and reporting

5. ERROR HANDLING
   • Format validation
   • API error handling
   • Network error handling
   • Comprehensive error messages

ARCHITECTURE
───────────────────────────────────────────────────────────────────

Modular Design:
• index.js - Event listeners & initialization

• Utils/ - Reusable utilities (parser, API, embed)

Data Flow:
User Input → Parser → Validator → API Call → Response Builder → Discord

HOW IT WORKS
───────────────────────────────────────────────────────────────────

1. User sends message in format: SKU.nomor/idtujuan
2. Bot detects transaction format automatically
3. Parser extracts SKU, nomor, and idtujuan
4. Validator checks data format and validity
5. Generate MD5 signature for Digiflazz authentication
6. Send POST request to Digiflazz API
7. Digiflazz processes transaction
8. Receive response and determine status
9. Build appropriate embed (success/failed/pending)
10. Reply to user with status
11. Log transaction to log channel (if configured)
